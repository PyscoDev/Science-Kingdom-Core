# Science-Kingdom-Core

The core repository holding system scripts, development archives, and automation tools.

## Directory Structure
* **`Main/`**: Core application scripts, modules, and utilities (including tools for birthdays, audio/ear input, and weather).
* **`Work on pendency/`**: Active task pipelines, orchestrator scripts, and development workbenches.
* **`Learning_Archive/`**: Historical learning code, threading trials, OOP practice, computer vision scripts, and Ollama experiments.
* **`Terminal_Scripts/`**: Automation scripts and utilities for Linux/Debian system maintenance.
* **`Configurations/`**: Setup notes and configuration files for local tools like Ollama.

## Requirements
* Python 3.x
* Ubuntu / Linux environment
* Check `requirements.txt` and `modules_needed.txt` for specific dependencies.
